= Configuration Guide
:toc: left

`dogu` supports overriding authoritative download URLs with mirror base URLs using `.dogu.properties`.

== File Resolution

`dogu` searches for `.dogu.properties` starting from the current working directory and traversing upwards to the root directory until a file is found.

== Format

Properties follow standard key-value formatting:

[source,properties]
----
# Mirror configurations
java.mirror=https://mirror.example.com/java
node.mirror=https://mirror.example.com/node
maven.mirror=https://mirror.example.com/maven
sbt.mirror=https://mirror.example.com/sbt
gradle.mirror=https://mirror.example.com/gradle
ant.mirror=https://mirror.example.com/ant
mill.mirror=https://mirror.example.com/mill
bazel.mirror=https://mirror.example.com/bazel
pants.mirror=https://mirror.example.com/pants
buck2.mirror=https://mirror.example.com/buck2
npm.mirror=https://mirror.example.com/npm
yarn.mirror=https://mirror.example.com/yarn
pnpm.mirror=https://mirror.example.com/pnpm
bun.mirror=https://mirror.example.com/bun
python.mirror=https://mirror.example.com/python
uv.mirror=https://mirror.example.com/uv
----
