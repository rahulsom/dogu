= Configuration Guide
:source-highlighter: highlight.js

`dogu` supports configuring standard tool base URLs using `config.json` files and environment variables.

== Default Base URLs

Default base URLs for all supported tools are embedded directly within `dogu` (from the repository's `config.json`).

== Configuration Overrides

You can override default base URLs by creating a user JSON configuration file:

1. **Environment Variable:** Set `DOGU_CONFIGURATION` to the path of your custom JSON configuration file.
2. **User Home Config:** Place a `config.json` file inside `$DOGU_HOME/config.json` (defaults to `~/.dogu/config.json`).

== JSON Format

In `config.json`, tool base URLs are grouped under the `baseUrls` object, where keys match tool names (such as `node`, `java`, `maven`) mapped to their base download URLs:

[source,json]
----
{
  "baseUrls": {
    "ant": "http://localhost:8080/archive.apache.org/dist/ant/binaries",
    "bazel": "http://localhost:8080/github.com/bazelbuild/bazel/releases/download",
    "buck2": "http://localhost:8080/github.com/facebook/buck2/releases/download",
    "bun": "http://localhost:8080/github.com/oven-sh/bun/releases/download",
    "gradle": "http://localhost:8080/services.gradle.org/distributions",
    "java": "http://localhost:8080/api.foojay.io/disco/v3.0/packages",
    "maven": "http://localhost:8080/archive.apache.org/dist/maven/maven-3",
    "mill": "http://localhost:8080/github.com/com-lihaoyi/mill/releases/download",
    "node": "http://localhost:8080/nodejs.org/dist",
    "npm": "http://localhost:8080/registry.npmjs.org/npm/-",
    "pants": "http://localhost:8080/github.com/pantsbuild/pants/releases/download",
    "pnpm": "http://localhost:8080/github.com/pnpm/pnpm/releases/download",
    "python": "http://localhost:8080/github.com/indygreg/python-build-standalone/releases/download",
    "sbt": "http://localhost:8080/github.com/sbt/sbt/releases/download",
    "uv": "http://localhost:8080/github.com/astral-sh/uv/releases/download",
    "yarn": "http://localhost:8080/github.com/yarnpkg/yarn/releases/download"
  }
}
----

== Programmatic Configuration Injection

When using `dogu` as a Go module dependency in another project, configuration can be initialized or injected programmatically:

[source,go]
----
cfg := config.NewConfig()
cfg.BaseURLs["node"] = "https://custom-node-mirror.internal/dist"

err := cli.RunWithConfig(args, cfg)
----
