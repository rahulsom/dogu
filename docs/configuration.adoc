= Configuration Guide
:source-highlighter: highlight.js

`dogu` supports configuring standard tool base URLs using `config.json` files and environment variables.

== Default Base URLs

Default base URLs for all supported tools are embedded directly within `dogu` (from the repository's `config.json`).

== Configuration Overrides

You can override default base URLs by creating a user JSON configuration file:

1. **Environment Variable:** Set `DOGU_CONFIGURATION` to the path of your custom JSON configuration file.
2. **User Home Config:** Place a `config.json` file inside `$DOGU_HOME/config.json` (defaults to `~/.dogu/config.json`).

== JSON Format

In `config.json`, tool base URLs are grouped under the `baseUrls` object, where keys match tool names (such as `node`, `java`, `maven`) mapped to their base download URLs. `dogu` supports single-line (`//`, `#`) and multi-line (`/* ... */`) comments in configuration files:

== URL Rewriting

`dogu` supports rewriting download URLs (both initial request URLs and HTTP 30x redirect locations) to route requests to internal proxies, mirrors, or Artifactory instances. This is particularly useful for tools like `java` where Foojay Disco API returns redirect URLs pointing to upstream binary releases (such as GitHub releases).

URL rewrite rules can be configured in `config.json` using either a JSON object (map format) or an array of rules:

=== Map Format

[source,json]
----
{
  "baseUrls": { ... },
  "rewrite": {
    "https://github.com/adoptium/temurin25-binaries/releases/download/": "https://artifactory.internal/temurin25/"
  }
}
----

=== Array Format

[source,json]
----
{
  "baseUrls": { ... },
  "rewrite": [
    {
      "from": "https://github.com/adoptium/temurin25-binaries/releases/download/",
      "to": "https://artifactory.internal/temurin25/"
    }
  ]
}
----

== Programmatic Configuration Injection

When using `dogu` as a Go module dependency in another project, configuration can be initialized or injected programmatically:

[source,go]
----
cfg := config.NewConfig()
cfg.BaseURLs["node"] = "https://custom-node-mirror.internal/dist"

err := cli.RunWithConfig(args, cfg)
----
