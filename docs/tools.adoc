= Supported Tools Reference

`dogu` manages tool installations in `$DOGU_HOME/candidates/<tool>/<version>`.

== Java / JVM Ecosystem

=== Java

* **CLI Flag:** `--java`
* **Default Base URL:** `https://api.foojay.io/disco/v3.0/packages`
* **Mirror Property:** `java.mirror`
* **Version Formats:** Major versions, exact versions, or vendor distribution suffixes (`-zulu`, `-tem`)
* **Examples:** `--java 21`, `--java 17-zulu`, `--java 25.0.3.0+9-tem`
* **Environment Variables Set:** `JAVA_<MAJOR>_HOME`, `JAVA_HOME`
* **Notes:** Integrated with Foojay Disco API; supports vendor specs (`-zulu`, `-tem`)

=== Apache Maven

* **CLI Flag:** `--maven`
* **Default Base URL:** `https://archive.apache.org/dist/maven/maven-3`
* **Mirror Property:** `maven.mirror`
* **Version Formats:** Major versions, major.minor, or exact semver versions
* **Examples:** `--maven 3`, `--maven 3.9`, `--maven 3.9.6`
* **Environment Variables Set:** `MAVEN_<MAJOR>_HOME`, `MAVEN_HOME`, `M2_HOME`
