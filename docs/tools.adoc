= Supported Tools Reference
:source-highlighter: highlight.js

`dogu` manages tool installations in `$DOGU_HOME/candidates/<tool>/<version>`.

== Java / JVM Ecosystem

=== Java

Integrated with Foojay Disco API; supports vendor specs (`-zulu`, `-tem`).
The default base URL is `https://api.foojay.io/disco/v3.0/packages`.

You can specify versions with `--java`.
This supports major versions, exact versions, or vendor distribution suffixes (e.g., `-zulu`, `-tem`).
E.g. `--java 21`, `--java 17-zulu`, `--java 25.0.3.0+9-tem`

It will set the following environment variables: `JAVA_<MAJOR>_HOME`, `JAVA_HOME`.

=== Groovy

Downloads Apache Groovy binary zips; requires Java.

Use `--groovy 4.0`. Accepts major, major.minor, or exact versions.
Sets `GROOVY_HOME` and `GROOVY_<MAJOR>_HOME`.

[source,bash]
----
dogu --java 21 --groovy 4.0 -- groovy --version
----

=== Kotlin

Downloads JetBrains JVM compiler zips; requires Java. Includes `kotlin` and `kotlinc`.

Use `--kotlin 2.1`. Accepts major, major.minor, or exact versions.
Sets `KOTLIN_HOME` and `KOTLIN_<MAJOR>_HOME`.

=== Scala

Downloads Scala 2 or Scala 3 distribution zips, selected by requested major version; requires Java.

Use `--scala 3.3`. Accepts major, major.minor, or exact versions.
Sets `SCALA_HOME` and `SCALA_<MAJOR>_HOME`.

=== Apache Maven

Downloads Apache Maven releases.
The default base URL is `https://archive.apache.org/dist/maven/maven-3`.

You can specify versions with `--maven`.
This supports major versions, major.minor, or exact semver versions.
E.g. `--maven 3`, `--maven 3.9`, `--maven 3.9.6`

It will set the following environment variables: `MAVEN_<MAJOR>_HOME`, `MAVEN_HOME`, `M2_HOME`.

=== sbt

The default base URL is `https://github.com/sbt/sbt/releases/download`.

You can specify versions with `--sbt`.
This supports major versions, major.minor, or exact semver versions.
E.g. `--sbt 1`, `--sbt 1.10`, `--sbt 1.10.10`

It will set the following environment variables: `SBT_<MAJOR>_HOME`, `SBT_HOME`.

=== Gradle

Downloads Gradle distribution zips.
The default base URL is `https://services.gradle.org/distributions`.

You can specify versions with `--gradle`.
This supports major versions, major.minor, or exact semver versions.
E.g. `--gradle 8`, `--gradle 8.10`, `--gradle 8.10.2`

=== Clojure CLI

Downloads the official Clojure CLI tools archive and installs its `clojure` and
`clj` launchers. Requires Java; installation currently supports Linux and macOS.

Use `--clojure` with a major, major.minor, or exact tools version, such as
`--clojure 1.12` or `--clojure 1.12.0.1530`. Sets `CLOJURE_HOME` and
`CLOJURE_<MAJOR>_HOME`.

=== Leiningen

Downloads the standalone Leiningen jar and provides the `lein` launcher.
Requires Java.

Use `--leiningen` with a major, major.minor, or exact version, such as
`--leiningen 2.13` or `--leiningen 2.13.0`. Sets `LEININGEN_HOME`,
`LEININGEN_<MAJOR>_HOME`, and `LEIN_HOME`.

== Additional Languages

All providers accept major, major.minor, or exact versions and set
`<TOOL>_HOME` and `<TOOL>_<MAJOR>_HOME`. Download base URLs can be overridden
with the existing `baseUrls` configuration; URL rewrite rules also apply.

[cols="1,1,3"]
|===
|Tool |Example |Distribution
|Go |`--go 1.24` |Official host archive selected from the go.dev JSON index; also sets `GOROOT`.
|Rust |`--rust 1.85` |Official standalone toolchain, including `rustc` and Cargo. Runs `install.sh` into the candidate directory.
|GHC (Haskell) |`--ghc 9.6` |Official GHC bindist. Runs `configure` and `make install` into the candidate directory.
|R |`--r 4.4` |Builds CRAN sources with `configure`, `make`, and `make install`. Sets `R_HOME` to the installed `lib/R` directory.
|Julia |`--julia 1.11` |Official host archive selected from Julia's JSON release index.
|Elm |`--elm 0.19.1` |Official compressed compiler executable. Supports x86-64 Linux, macOS, Windows, and native macOS ARM64.
|Ruby |`--ruby 3.4` |Builds official Ruby sources, including RubyGems, with `configure`, `make`, and `make install`.
|Lua |`--lua 5.4` |Builds official Lua sources, including `lua` and `luac`, with the host's make target and `make install`.
|===

Rust, GHC, R, Ruby, and Lua currently support Linux and macOS on x86-64 and ARM64.
Rust requires a shell and a system linker/C toolchain to compile programs.
GHC requires a shell, make, a C compiler, and the runtime libraries required by
its bindist (including GMP; Linux selects the oldest available Debian baseline
from Debian 10 through Debian 13).
R requires make, C and Fortran compilers, and CRAN's build dependencies
(including readline, zlib, bzip2, xz, PCRE2, and libcurl development files).
R builds without X11; building from source can take several minutes.
Ruby requires a shell, make, a C compiler, and development libraries for
OpenSSL, libyaml, and zlib for its standard extensions and RubyGems.
Ruby builds without documentation; building from source can take several minutes.
Lua requires make and a C compiler, plus readline development files on Linux.
Ruby uses `https://cache.ruby-lang.org/pub/ruby` (`index.txt` for discovery);
Lua uses `https://www.lua.org/ftp` for discovery and source downloads.
These providers install within `$DOGU_HOME` without requesting administrator access.
