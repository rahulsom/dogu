= Supported Tools Reference

`dogu` manages tool installations in `$DOGU_HOME/candidates/<tool>/<version>`.

== Java / JVM Ecosystem

|===
| Tool | Flag | Version Formats | Examples | Environment Variables Set | Notes

| Java | `--java` | Major versions, exact versions, or vendor distribution suffixes (`-zulu`, `-tem`) | `--java 21`, `--java 17-zulu`, `--java 25.0.3.0+9-tem` | `JAVA_<MAJOR>_HOME`, `JAVA_HOME` | Integrated with Foojay Disco API; supports vendor specs (`-zulu`, `-tem`)
| Apache Maven | `--maven` | Major versions, major.minor, or exact semver versions | `--maven 3`, `--maven 3.9`, `--maven 3.9.6` | `MAVEN_<MAJOR>_HOME`, `MAVEN_HOME`, `M2_HOME` | Downloads Apache Maven releases
| sbt | `--sbt` | Major versions, major.minor, or exact semver versions | `--sbt 1`, `--sbt 1.10`, `--sbt 1.10.10` | `SBT_<MAJOR>_HOME`, `SBT_HOME` | Downloads sbt release archives
| Gradle | `--gradle` | Major versions, major.minor, or exact semver versions | `--gradle 8`, `--gradle 8.10`, `--gradle 8.10.2` | `GRADLE_<MAJOR>_HOME`, `GRADLE_HOME` | Downloads Gradle distribution zips
|===
