== Node.js / JavaScript Ecosystem

=== Node.js

Downloads official nodejs.org dist archives.
The default base URL is `https://nodejs.org/dist`.

You can specify versions with `--node`.
This supports major versions, major.minor, or exact semver versions.
E.g. `--node 20`, `--node 22.11`, `--node 22.11.0`

It will set the following environment variables: `NODE_<MAJOR>_HOME`, `NODE_HOME`.
