= dogu
:source-highlighter: highlight.js

image::images/toolbox.png[도구 toolbox,width=320]

`dogu` is a multiplatform CLI developer tool manager written in Go.

For user-facing documentation, usage instructions, configuration guides, and supported tool references, please visit the https://rahulsom.github.io/dogu/[dogu Documentation Site].

== Repository Structure

* `cmd/dogu/`: Entry point for the `dogu` CLI binary.
* `pkg/cli/`: CLI parsing, flags handling, execution runner, and TUI progress rendering.
* `pkg/config/`: Configuration parsing and resolution.
* `pkg/downloader/`: HTTP archive download, extraction (`.tar.gz`, `.zip`, `.tar.xz`, `.tar.zst`), and progress bars.
* `pkg/env/`: Environment variable resolution and PATH construction for invoked commands.
* `pkg/tools/`: Tool providers and resolution logic for Java, Node.js, Maven, Gradle, Go/Python/Rust ecosystem tools, etc.
* `docs/`: Source AsciiDoc files for the user documentation published to GitHub Pages.
* `testdata/`: Test data fixtures, including Cachew configuration for mirror integration tests.

== Building `dogu`

Ensure you have Go installed (1.23 or newer as specified in `go.mod`).

To compile all packages:

[source,bash]
----
go build ./...
----

To build the `dogu` binary:

[source,bash]
----
go build -o dogu ./cmd/dogu
----

== Running Tests

To run all unit and integration tests:

[source,bash]
----
go test -v ./...
----

Or using `gotestsum` with coverage and race detection (as used in CI):

[source,bash]
----
go run gotest.tools/gotestsum@latest --format testdox -- -race -cover ./...
----

== Testing with a Local Mirror (Cachew)

You can run a local pass-through caching mirror using link:https://github.com/block/cachew[Cachew] and Docker to test mirror provisioning:

1. **Start the Cachew container:**
+
[source,bash]
----
docker run -d --rm \
  --name dogu-cachew-mirror \
  -p 8080:8080 \
  -v "$(pwd)/testdata/cachew.hcl:/app/cachew.hcl:ro" \
  ghcr.io/block/cachew:latest \
  --config /app/cachew.hcl
----

2. **Configure `config.json`:**
+
Create a `config.json` file in `$DOGU_HOME/config.json` (or set `DOGU_CONFIGURATION`) pointing to the local mirror:
+
[source,json]
----
{
  "baseUrls": {
    "maven": "http://localhost:8080/archive.apache.org/dist/maven/maven-3",
    "node": "http://localhost:8080/nodejs.org/dist"
  }
}
----

3. **Test with `go run cmd/dogu/main.go`:**
+
Run `dogu` with `-v` (verbose) to observe downloads routing through the mirror:
+
[source,bash]
----
go run cmd/dogu/main.go -v --maven 3.9.6 -- mvn -v
go run cmd/dogu/main.go -v --node 20.18.0 -- node -v
----

4. **Stop the container when finished:**
+
[source,bash]
----
docker stop dogu-cachew-mirror
----

== Generating Documentation

You can run this command to generate the HTML documentation from the AsciiDoc sources in `docs/`.

[source,bash]
----
docker run --rm -v $(pwd):/documents \
    asciidoctor/docker-asciidoctor:main asciidoctor \
    --destination-dir build/docs \
    --backend=html5 \
    --out-file index.html \
    docs/index.adoc
----
